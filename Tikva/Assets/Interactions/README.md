# Взаимодействия

Левая кнопка мыши выполняет действие. В режиме камер цель выбирается курсором, в первом лице — центром экрана. До нажатия ЛКМ видна только обводка. Текст появляется только при неудачном нажатии: объект далеко либо подозрительный предмет нельзя взять в режиме камер. После этого сообщение плавно гаснет. При успешном подборе или открытии двери текста нет. Видимые через коллайдеры объекты подсвечиваются и за пределами Reach Distance (по умолчанию 3 м), но действие доступно только в пределах этой дистанции.

- Жёлтая обводка — доступный предмет или дверь.
- Красная обводка + «подозрительное действие» — подозрительный предмет в третьем лице: подобрать нельзя.
- Если предмет или дверь далеко, обводка остаётся жёлтой или красной по типу предмета, а после ЛКМ подсказка показывает «вы далеко».
- «открыть» / «закрыть» — дверь.
- В режиме камер сообщение об отказе следует за курсором; при наведении используется изображение стандартного курсора-ссылки Windows, которое Unity переключает один раз без ежикадрового мигания.
- В первом лице подсказка находится рядом с центром прицела.

У игрока один слот правой руки. При подборе нового предмета предыдущий отсоединяется и падает с Rigidbody. При выходе из первого лица подозрительный предмет сбрасывается автоматически, включая автоматический выход из слепой зоны. Обычный предмет остаётся в руке.

В SurvivalPlayerController находится публичная строка currentHeldItem: имя предмета либо пустая строка. На PlayerInteraction есть ссылки Held Item, Right Hand — точка `RightHandGrip` внутри ладони — и First Person Anchor. Последняя точка находится под `Main Camera`; её положение можно менять для общего ракурса всех предметов в первом лице. В `Interaction HUD` параметры Text Hold Seconds и Text Fade Seconds регулируют время показа и исчезновения подсказки.

Предмет в первом лице слегка качается при ходьбе и с задержкой следует за поворотом камеры. В `PlayerInteraction` параметры Walk Bob Amount / Frequency задают силу и частоту шага, Turn Position Lag / Rotation Lag — отставание при повороте, Motion Smooth Time — плавность возврата. Значения First Person Held Position / Rotation остаются базовой позой предмета.

## Новый предмет

1. Добавить InteractionObject на корень предмета, выставить Kind = Pickup и Display Name.
2. Добавить Collider (BoxCollider подходит для простых предметов). При необходимости Rigidbody: для неподвижного исходного размещения включить Is Kinematic, выключить Use Gravity.
3. Suspicious ограничивает подбор первым лицом и включает красную подсказку в остальных видах.
4. Available Hover Text задаёт подсказку для доступного действия, Suspicious Hover Text — предупреждение в режиме камер. Too Far Hover Text — сообщение вне дистанции; для дверей Opened Door Hover Text задаёт текст при открытой створке. Hover Text Size регулирует размер текста у конкретного объекта. Пустая строка использует стандартный текст.
5. Third Person Held Position / Rotation задают позу предмета относительно `RightHandGrip` в режиме камер. First Person Held Position / Rotation задают отдельную позу относительно `FirstPersonItemAnchor` в первом лице. Все углы — градусы по X/Y/Z. Их можно менять на компоненте `InteractionObject`; во время Play Mode изменение сразу видно. Масштаб предмета сохраняется.
6. Reach Distance задаёт дальность действия. InteractionOutline автоматически добавляется при запуске, Width регулирует толщину обводки. Объект должен быть на обычном слое, не Ignore Raycast.

## Новая дверь или дверца

1. InteractionObject с Kind = Door и Collider на движущейся створке.
2. Создать Empty-петлю у края створки, сделать створку её дочерним объектом и назначить Empty в Hinge.
3. Hinge Axis, Open Angle и Opening Duration задают ось, угол и длительность открытия. Ось задаётся локально относительно петли.

Для EntranceDoor петля уже создана. Crowbar отмечен как Suspicious, Screwdriver — обычный предмет. Collider остаётся на двери и следует за ней при открытии. Обводка не изменяет исходные материалы и не проходит сквозь стены.

Проверка Play Mode: InteractionChecks.Run().
