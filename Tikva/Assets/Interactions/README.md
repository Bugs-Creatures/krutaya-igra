# Взаимодействия

Левая кнопка мыши выполняет действие. В режиме камер цель выбирается курсором, в первом лице — центром экрана. До нажатия ЛКМ видна только обводка. Текст появляется только при неудачном нажатии: объект далеко либо подозрительный предмет нельзя взять в режиме камер. После этого сообщение плавно гаснет. При успешном подборе или открытии двери текста нет. Видимые через коллайдеры объекты подсвечиваются и за пределами Reach Distance (по умолчанию 3 м), но действие доступно только в пределах этой дистанции.

- Жёлтая обводка — доступный предмет или дверь.
- Красная обводка + «подозрительное действие» — подозрительный предмет в третьем лице: подобрать нельзя.
- Если предмет или дверь далеко, обводка остаётся жёлтой или красной по типу предмета, а после ЛКМ подсказка показывает «вы далеко».
- «открыть» / «закрыть» — дверь.
- В режиме камер сообщение об отказе следует за курсором; при наведении используется изображение стандартного курсора-ссылки Windows, которое Unity переключает один раз без ежикадрового мигания.
- В первом лице подсказка находится рядом с центром прицела.

У игрока один слот правой руки. При подборе нового предмета предыдущий отсоединяется и падает с Rigidbody. При выходе из первого лица подозрительный предмет сбрасывается автоматически, включая автоматический выход из слепой зоны. Обычный предмет остаётся в руке.

В SurvivalPlayerController находится публичная строка currentHeldItem: имя предмета либо пустая строка. На PlayerInteraction есть ссылки Held Item, Right Hand — точка `RightHandGrip` внутри ладони — и First Person Anchor. Последняя точка находится под `Main Camera`; её положение можно менять для общего ракурса всех предметов в первом лице. В `Interaction HUD` параметры Text Hold Seconds и Text Fade Seconds регулируют время показа и исчезновения подсказки.

Предмет в первом лице слегка качается при ходьбе и с задержкой следует за поворотом камеры. В `PlayerInteraction` параметры Walk Bob Amount / Frequency задают силу и частоту шага, Turn Position Lag / Rotation Lag — отставание при повороте, Motion Smooth Time — плавность возврата. Значения First Person Held Position / Rotation остаются базовой позой предмета.

## Новый предмет

1. Добавить InteractionObject на корень предмета, выставить Kind = Pickup и Display Name.
2. Добавить Collider (BoxCollider подходит для простых предметов). При необходимости Rigidbody: для неподвижного исходного размещения включить Is Kinematic, выключить Use Gravity.
3. Suspicious ограничивает подбор первым лицом и включает красную подсказку в остальных видах.
4. Available Hover Text задаёт подсказку для доступного действия, Suspicious Hover Text — предупреждение в режиме камер. Too Far Hover Text — сообщение вне дистанции; для дверей Opened Door Hover Text задаёт текст при открытой створке. Hover Text Size регулирует размер текста у конкретного объекта. Пустая строка использует стандартный текст.
5. Third Person Held Position / Rotation задают позу предмета относительно `RightHandGrip` в режиме камер. First Person Held Position / Rotation задают отдельную позу относительно `FirstPersonItemAnchor` в первом лице. Все углы — градусы по X/Y/Z. Их можно менять на компоненте `InteractionObject`; во время Play Mode изменение сразу видно. Масштаб предмета сохраняется.
6. Reach Distance задаёт дальность действия. InteractionOutline автоматически добавляется при запуске, Width регулирует толщину обводки. Объект должен быть на обычном слое, не Ignore Raycast.

## Новая дверь или дверца

1. InteractionObject с Kind = Door и Collider на движущейся створке.
2. Создать Empty-петлю у края створки, сделать створку её дочерним объектом и назначить Empty в Hinge.
3. Hinge Axis, Open Angle и Opening Duration задают ось, угол и длительность открытия. Ось задаётся локально относительно петли.

Для EntranceDoor петля уже создана. Crowbar отмечен как Suspicious, Screwdriver — обычный предмет. Collider остаётся на двери и следует за ней при открытии. Обводка не изменяет исходные материалы и не проходит сквозь стены.

Проверка Play Mode: InteractionChecks.Run().

## Звуки

Все клипы необязательные: пустое поле означает тишину.

- Каждый предмет (`vodka`, `crowbar`, `screwdriver`) → `Interaction Object` → `Sounds (optional)` → `Drop Sound`: удар о поверхность после сброса из руки, один раз за падение.
- `EntranceDoor` → `Interaction Object` → `Open Sound` / `Close Sound`: открытие / закрытие. `Sound Volume` — громкость предмета или двери.

AudioSource создаётся автоматически только при проигрывании назначенного клипа. Для новых предметов и дверей используются те же поля Interaction Object.

## Zaika и крюк кошка

На `Zaika` компонент `Zaika Dialogue` хранит ссылку `Hook Reward`, выбранную ветку и `Speech Pause` (пауза после точек, по умолчанию 0,18 с). Награда выдаётся один раз. Повторные реплики не блокируют игрока.

`GrapplingHook` изначально выключен в сцене и появляется после диалога. Это корень предмета с Rigidbody, BoxCollider, InteractionObject и InteractionOutline. Белый куб — дочерний `Visual`.

Чтобы заменить куб, в Edit Mode развернуть неактивный `GrapplingHook`, удалить только `Visual` и добавить свою модель дочерним объектом. Настроить её локальные позицию, поворот и масштаб. Подогнать BoxCollider на корне под модель; дополнительные Rigidbody на модель не добавлять. Положение в руке задаётся в полях Held Position / Rotation корневого InteractionObject. Корневой объект и ссылка Hook Reward должны сохраниться.

## Оконное обучение

Новостная лента полностью удалена. Карточки обучения могут открываться в режиме камер и в первом лице. Они ждут завершения диалога или просмотра карты, объединяются в очередь с кнопками «Далее» и «Понятно» и не повторяются в рамках прохождения.

Подсказка про подозрительные предметы появляется после трёх неудачных нажатий на один подозрительный предмет в режиме камер либо после первого принудительного сброса подозрительного предмета при попадании под камеру. Успешный подбор в первом лице сам по себе её не вызывает.

Подсказка про поиск уроненных предметов появляется при первом включении ручного `Survival Player Controller → First Person` после того, как уже появился уроненный игроком предмет. Обычный вход в слепую зону эту подсказку не вызывает. Само удержание ПКМ для подсветки работает во всех режимах первого лица, включая слепые зоны. Цвет — `Dropped Item Highlight → Highlight Color`. Толщина совпадает с обычной обводкой конкретного предмета (`Interaction Outline → Width`).

Карта постоянно принадлежит игроку после подбора и не занимает руку. Она открывается по M, закрывается любой кнопкой или крестиком и остаётся у игрока. При подборе показывается оконная подсказка про M. Изображение карты берётся из `Map Item` (сейчас `Assets/Interactions/map.jpg`).

Картинки обучения можно назначить в `Player Tutorial Hud`: `Map Image`, `Suspicious Image`, `Dropped Items Image`, либо на RawImage внутри карточки. Если поле пустое, используется заполнитель.
## Карточки в сцене

Все карточки обучения сохранены в `Tutorial Cards Canvas → Tutorial overlay`: `Map`, `Suspicious`, `DroppedItems`. Вне Play Mode включить `Tutorial overlay` и нужную карточку для просмотра и редактирования. Корни карточек и их кнопки, тексты и изображения можно менять прямо в Hierarchy. При запуске скрипт скрывает их до нужного события. Карточки не создаются заново кодом.

`Player Tutorial Hud` ссылается на `Tutorial Overlay`, `Map Card`, `Suspicious Card`, `Dropped Card`. Текст берётся из сохранённых TMP-компонентов. Картинку можно назначить прямо на дочернем `Tutorial image` в RawImage; поля изображений на Player Tutorial Hud работают как необязательные переопределения. Кнопка «Далее» и счётчик страниц обновляются автоматически.

Подсветка уроненных предметов действует ровно во время удержания ПКМ. При отпускании или открытии модального окна она выключается. Толщина совпадает с обычной обводкой предмета. Над ним показывается название и расстояние, например `крюк-кошка 25.5м`, в цвете подсветки. Подложки текста непрозрачные.



## Крафт крюка кошки с верёвкой

Обычный крюк-кошка от Заики теперь не подозрительный. `Player → Rope Hook Crafting` содержит ссылки `Rope`, `Hook` и `Result Prefab`. Подбор второго ингредиента при первом в руке расходует оба предмета и создаёт результат в позиции второго. Рука освобождается; результат остаётся на земле.

Результат — `Assets/Interactions/RopeGrapplingHook.prefab`, название «Крюк-кошка на верёвке», подозрительный предмет. Созданная связка сразу доступна для поиска удержанием ПКМ. Белый куб — дочерний `Visual` внутри префаба; для замены модели менять только этот дочерний объект, сохранив корневые компоненты и настроив BoxCollider под новую геометрию.

## Инструменты и вход в подвал

`Ключ`, `Лопата`, `Плоскогубцы` — подбираемые предметы. Ключ и лопата подозрительные, плоскогубцы обычные. Заглушка каждого предмета находится в дочернем `Visual`; для замены модели менять этот дочерний объект, сохраняя корневые скрипты, Rigidbody и Collider. После замены подогнать Collider и позу в руке.

`Цепи → Tool Action Target` использует `Required Tool` (Фомка). Взлом подозрительный и доступен только в первом лице. `Intact Visual` / `Broken Visual` — целая и сломанная модель. Сейчас это кубы: `IntactVisual` и `BrokenVisual`. Заменять их можно вместе с обновлением ссылок в компоненте. После взлома целая модель скрывается, сломанная показывается, коллайдеры цепей отключаются, освобождая взаимодействие с дверью.

`Дверь в подвал → Tool Action Target`: `Chains` — обязательные для снятия цепи, `Required Tool` — Ключ, `Destination` — `teleport place`. После снятия цепей ключ в руке открывает дверь. Действие не подозрительное. Игрок переносится на точку, принимает её направление и принудительно переходит в ручное первое лицо. Ключ остаётся в руке; дверь запоминает открытый замок до конца текущего прохождения.

## CrimsonMass Idle и финальный разговор

`CrimsonMass_Idle → Crimson Mass Dialogue` содержит все восемь реплик и семь единственных ответов. Фраза появляется по буквам и после завершения печати остаётся до выбора ответа. Ответы показываются без тире. Чёрная подложка растёт по мере появления букв и увеличивается по высоте только при переходе видимого текста на следующую строку. После печати финальной фразы появляется Топор, затем диалог автоматически завершается через `Final Line Hold` секунд, без кнопки закрытия. При повторном обращении монстр коротко говорит «Удачи.» без блокировки управления; длительность после печати — `Farewell Hold`.

Текст монстра красный, отдельные буквы двигаются плавной волной. Подпись `???:` — отдельный неподвижный текст. Цвет и скорость печати задаются в `Text Color`, `Letters Per Second`, волна — в `Wave Amplitude`, `Wave Speed`, `Wave Character Phase`. Тексты можно менять в массиве `Lines`.

`Axe` — неподозрительный Топор, изначально выключенный в сцене. Белый куб внутри `Visual` заменяется своей моделью без удаления корневых компонентов. После выдачи предмет доступен для поиска удержанием ПКМ.

При первом успешном входе через дверь подвала Ключ расходуется и уничтожается. Открытый замок сохраняется на время прохождения, повторные входы не требуют ключа. Дверь по-прежнему переносит на `teleport place` и включает первое лицо.

## Щиток и отключение камер

`Держатель щитка → Electrical Panel` содержит ссылки на крышку, щиток, четыре винта и целый/перерезанный провод. Вначале доступна только крышка. Без Отвёртки в руке появляется «нужно чем-то открутить»; с Отвёрткой винты скрываются, крышка отделяется и падает с Rigidbody. Направление и сила небольшого толчка задаются в `Cover Fall Direction` / `Cover Push`.

После снятия крышки доступен щиток. Без Плоскогубцев появляется «чем-то нужно перерезать». С Плоскогубцами целый провод выключается, повреждённый включается, взаимодействие со щитком и крышкой завершается. Инструменты остаются у игрока. `Survival Camera Rig.CamerasDisabled` закрепляет первое лицо до конца текущего прохождения, включая помещения и все уличные зоны; обычное переключение режима уже не возвращает камеры.

Материалы синих и зелёных проводов: `Assets/Interactions/Materials/Wire_Blue.mat` и `Wire_Green.mat`.

Обновлённая зона `bakery_camera` находится в `Camera activation areas → bakery_camera activation area`, дополнительные полосы — внутри этого объекта. Они назначены в `Fixed Camera Zone → Additional Volumes` и соответствуют новому ракурсу. Остальные зоны сохранены.

## Позы предметов в руке

Настроены отдельные позы для Отвёртки, Фомки, Водки, Верёвки, Ключа, Лопаты, Плоскогубцев, Топора, Крюка-кошки и префаба Крюка-кошки на верёвке. В третьем лице к ладони привязывается рукоять, а не центр геометрии. Исправлен удалённый корень Плоскогубцев с сохранением положения модели и коллайдера в сцене. Карта по-прежнему собирается в постоянное владение и не занимает руку.

На каждом предмете в `Interaction Object` доступны `Third Person Held Position / Rotation` и отдельные `First Person Held Position / Rotation / Scale`. Последний масштаб применяется только к показу от первого лица: при возвращении в руку и броске исходный мировой размер восстанавливается. Покачивание и инерция первого лица сохраняются.

Топор и Лопата показаны в первом лице ближе к камере: нижняя часть рукоятей намеренно уходит за экран. Лопата повёрнута лицевой стороной к игроку, режущая кромка Топора направлена вперёд. Инерция применяется по осям камеры перед базовым поворотом предмета, поэтому горизонтальное запаздывание сохраняет направление при любой ориентации модели. В третьем лице Водка лежит поперёк ладони, с хватом за середину корпуса.

`Player → Held Item Hand Pose` плавно сгибает пальцы правой руки поверх текущей анимации, пока игрок держит предмет в третьем лице. `Grip Strength` задаёт степень сгибания, `Blend Time` — время перехода. После освобождения руки восстанавливается обычная анимация пальцев.

`Player → First Person Held Item Renderer` временно переносит предмет в руке и его дочерние объекты на слой 31 `FirstPersonHeldItem`. В `PC_Renderer` и `Mobile_Renderer` добавлен `First Person Held Item`: он рисует исходные материалы после окружения с собственной очищенной глубиной. Стены не обрезают предмет, а его собственные поверхности корректно перекрывают друг друга. Глубина окружения сохраняется. После броска, передачи NPC или возвращения к виду камер восстанавливаются исходные слои, тени и настройки окклюзии. Слой 31 зарезервирован для этого механизма; на обычные объекты сцены его назначать не нужно.

Зоны разговора NPC не перехватывают выбор предметов за их широкими коллайдерами. Стены и прочие твёрдые препятствия по-прежнему останавливают луч взаимодействия. Топор монстра дополнительно сбрасывается за пределами его коллайдера: выбирается свободное место на поверхности со стороны игрока или рядом с ней.

`drunk → Drunk Dialogue` имеет отдельные `Bottle Grip`, `Bottle Local Position` и `Bottle Local Rotation`. Бутылка после передачи лежит на точке `VodkaGrip` внутри правой кисти, независимо от настроек хвата игрока. `Held Item Hand Pose` на NPC использует `Hand Bone` и `External Held Item`, сгибая пальцы только после получения бутылки.

В `Interaction HUD → Interaction Prompt` прицел первого лица — векторное кольцо, которое заполняется при наведении на доступную цель в пределах дистанции взаимодействия. Без цели или вне дистанции остаётся пустым. Во время выбора диалога, карты и других модальных окон скрывается. `Reticle Diameter` (по умолчанию 8), `Reticle Thickness` и `Reticle Color` задают размер, толщину и цвет.

## Пауза

`Pause Canvas → Pause window` — сохранённое в сцене окно с крестиком и двумя слайдерами. `Player → Pause Menu` содержит ссылки на его элементы. Escape открывает/закрывает паузу, крестик закрывает её. Чувствительность (0.01–0.60, значение справа) меняет `Survival Player Controller.mouseSensitivity`, «Звук» (0–100%) — общий `AudioListener.volume`. Значения сохраняются при повторном открытии меню в текущем прохождении.

Пауза сохраняет прежние `Time.timeScale`, `AudioListener.pause`, состояние курсора и модальную блокировку, останавливает игровой мир и звук и восстанавливает их при закрытии. Диалоги, карта и подсказки не принимают ввод из меню и не продолжают печать/таймеры на паузе. Для игровых таймеров, которым нужен ход времени без зависимости от timeScale, используется замораживаемый `PauseMenu.GameplayUnscaledTime`. `EventSystem` с `InputSystemUIInputModule` обслуживает стандартные uGUI Slider/Button даже при timeScale=0.
